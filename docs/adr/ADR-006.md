# ADR-006: OPSSAT-AD as the build dataset

Status: Accepted (consequences amended)

ESA-ADB verified at 11.6 GB zipped across 3 missions; against one Mac mini, 19 days solo, $150 credits, that's the whole sprint. OPSSAT-AD: 18.5 MB, CC-BY 4.0, published split and metrics make methodology defensible by construction. Cost: no command context, so the telecommand false-positive story is unavailable. Recovery: ground-truth labels let the eval harness measure verifier rejection accuracy after the fact, a stronger claim than a synthetic demo beat because it's measured on a public benchmark. ESA-ADB stays cited as operator-requirements source and post-hackathon scale-up.
